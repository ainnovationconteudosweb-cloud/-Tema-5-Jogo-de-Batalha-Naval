# Tema 5 – Jogo de Batalha Naval

Este trabalho implementa a lógica do jogo Batalha Naval
utilizando um tabuleiro representado por uma matriz 5x5.

O jogador possui um número limitado de tentativas para
descobrir a posição de um navio escondido no tabuleiro.

Conceitos utilizados:
- Matrizes
- Estruturas condicionais (if / else)
- Estrutura de repetição (while)
- Controle de fluxo do jogo

Linguagem utilizada: Python
